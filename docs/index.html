Check

Footnote's search runs against a real pgvector database. Barometer's browser test signs up, opens the emailed link, unsubscribes and deletes the account. MagicStream is checked through nginx, the way a visitor reaches it.

Pack

Each app builds a layered Docker image and runs as a non-root user in the final layer. The image is started and probed before it can leave.

docker compose -f compose.yml \
  -f compose.dev.yml watch

Ship

Footnote and Barometer push to GitHub's container registry, tagged latest and with the commit. MagicStream is built and tested from its author's repository but not republished, because its code has no license.
