Every push, tested, packed and shipped

Three apps run through GitHub Actions on every push: tests against real databases, a browser driving the sign-up flow, Docker images built and started before anything is published. This board reads their latest runs live from GitHub.

Test

Footnote's store tests run against a pgvector Postgres started beside them. Barometer's job starts MongoDB, a mail catcher and Inngest's dev server, then a real browser signs up, opens the emailed link, unsubscribes and deletes the account. MagicStream is checked through nginx, the way a browser reaches it.

Pack

Each app builds a multi-stage Docker image: dependencies, a dev stage for live reload, a build stage, and a small runtime stage that runs as a non-root user. The image is started and probed before it can ship.

docker compose -f compose.yml \
  -f compose.dev.yml watch

Ship

On main, Footnote and Barometer publish to GitHub's container registry, tagged latest and the commit. Barometer's site deploys on Vercel, Footnote's results page on GitHub Pages. MagicStream is built and tested from its author's repo but not republished: its code has no license.
